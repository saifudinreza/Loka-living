Alur Auth Loka Living

Tiga alur utama. Dua jenis token: access token (JWT, 15 menit, dikirim di header) dan refresh token (30 hari, di cookie httpOnly, hanya hash-nya disimpan di database).

1. Register & login 2. Refresh & logout 3. Login Google Swagger UI

1. Register & login biasa

Register dan login menghasilkan response yang sama: access token di body, refresh token di cookie.

sequenceDiagram
  autonumber
  participant B as Browser
  participant API as Backend
  participant DB as Database
  B->>API: POST /api/auth/register {email, password, name}
  API->>API: rapikan email, validasi, hash password (argon2id)
  API->>DB: INSERT user (ON CONFLICT DO NOTHING)
  alt email sudah ada
    API-->>B: 409 EMAIL_TAKEN
  else baru
    API->>DB: simpan hash refresh token (family baru)
    API-->>B: 201 {access_token, user} + Set-Cookie refresh_token
  end
  Note over B,API: Login: sama, tapi cek password.
Email tak ada / password salah / akun Google / akun dihapus
semuanya 401 INVALID_CREDENTIALS (pesan & waktu sama)
  B->>API: POST /api/auth/login {email, password}
  API->>DB: cari user, verify password
  API-->>B: 200 {access_token, user} + Set-Cookie refresh_token
  B->>API: GET /api/auth/me (Authorization: Bearer access_token)
  API-->>B: 200 {user}

2. Refresh token & logout

Saat access token habis (401), frontend memanggil /refresh. Setiap refresh token hanya boleh dipakai sekali (rotasi). Memakai token lama lagi dianggap pencurian dan seluruh sesi (family) dicabut.

sequenceDiagram
  autonumber
  participant B as Browser
  participant API as Backend
  participant DB as Database
  B->>API: POST /api/auth/refresh (cookie refresh_token)
  API->>DB: BEGIN, cari hash token FOR UPDATE
  alt tidak ditemukan
    API-->>B: 401 REFRESH_TOKEN_INVALID + hapus cookie
  else sudah dicabut (dipakai ulang)
    API->>DB: cabut SELURUH family
    API-->>B: 401 REFRESH_TOKEN_REUSED + hapus cookie
  else kedaluwarsa
    API-->>B: 401 REFRESH_TOKEN_EXPIRED + hapus cookie
  else normal
    API->>DB: cabut token lama, simpan token baru (family sama)
    API-->>B: 200 {access_token} + Set-Cookie token baru
  end
  Note over B,API: Dua refresh paralel dengan cookie sama:
FOR UPDATE membuat tepat satu yang berhasil
  B->>API: POST /api/auth/logout
  API->>DB: cabut token ini saja (perangkat lain tetap login)
  API-->>B: 204 + hapus cookie (selalu, idempoten)

3. Login dengan Google

OAuth 2.0 authorization code flow dengan PKCE. Access token tidak lewat URL; frontend mengambilnya lewat /refresh setelah redirect. Coba dengan membuka /api/auth/google di browser (butuh GOOGLE_* di .env, kalau kosong menjawab 503).

sequenceDiagram
  autonumber
  participant B as Browser
  participant API as Backend
  participant G as Google
  participant DB as Database
  B->>API: GET /api/auth/google
  API->>API: buat state + code_verifier (PKCE)
  API-->>B: 302 ke Google + cookie state & verifier (10 menit)
  B->>G: login & setuju
  G-->>B: 302 ke /api/auth/google/callback?code&state
  B->>API: GET /api/auth/google/callback (+ cookie)
  alt state tidak cocok dengan cookie
    API-->>B: 302 FRONTEND/auth/callback?error=google_state_mismatch
  else cocok
    API->>G: tukar code + code_verifier
    G-->>API: id_token (sub, email, email_verified, name)
    alt email belum terverifikasi
      API-->>B: 302 ...?error=google_email_unverified
    else
      API->>DB: cari google_id, atau hubungkan email yang sama, atau buat user baru
      API->>DB: simpan hash refresh token (family baru)
      API-->>B: 302 FRONTEND/auth/callback + Set-Cookie refresh_token
    end
  end
  B->>API: POST /api/auth/refresh (dari halaman /auth/callback frontend)
  API-->>B: 200 {access_token, user}
  • Akun email/password yang sama: dihubungkan ke Google. Kalau emailnya belum pernah terverifikasi, password lamanya dibuang dan sesinya dicabut (mencegah pembajakan lewat pendaftaran dengan email korban).
  • Kode error callback: google_state_mismatch, google_access_denied, google_exchange_failed, google_email_unverified, google_email_invalid, google_account_conflict, google_account_disabled, google_login_failed, google_auth_disabled.
